# TFG---IA-DE-PREDICCION-FOTOVOLTAICA
En este repositorio se recoge el desarrollo de dos modelos de predicción de rendimiento fotovoltaico, uno para un emplazamiento A anonimizado y otro para Lorca, Murcia.

ARCHIVOS CLAVE:

ForecastPlantaA.ipynb -> Modelo del emplazamiento A anonimizado.
ForecastLorca.ipynb -> Modelo de Lorca, Murcia.
PlantaA_processed.csv -> Dataset del emplazamiento A anonimizado.
Lorca_processed.csv -> Dataset de Lorca, Murcia.
