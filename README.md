# TFG---IA-DE-PREDICCION-FOTOVOLTAICA
En este repositorio se recoge el desarrollo de dos modelos de predicción de rendimiento fotovoltaico, uno para Santander, Cantabria y otro para Lorca, Murcia.

ARCHIVOS CLAVE:

ForecastCTC.ipynb -> Modelo de Santander, Cantabria.
ForecastLorca.ipynb -> Modelo de Lorca, Murcia.
CTC_processed.csv -> Dataset de Santander, Cantabria.
Lorca_processed.csv -> Dataset de Lorca, Murcia.
